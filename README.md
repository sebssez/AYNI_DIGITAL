# Kallpa Cacao · E-Commerce & Gestión
Aplicación web modular con Frontend estático optimizado (`public/`) y API REST en Node.js + Express + MySQL (`src/`).

## Instalación
1. Ejecuta `npm install`
2. Importa `sql/schema.sql` en tu servidor MySQL
3. Configura tus credenciales en `.env`
4. Inicia el servidor con `npm run dev`
